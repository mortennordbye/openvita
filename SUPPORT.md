# Support

- **How do I...?** Start with the [README](README.md) and
  [CVs with OpenVita](https://mortennordbye.github.io/openself/openvita/) in the OpenSelf docs.
- **Something is broken, or an idea:** open an [issue](https://github.com/mortennordbye/openvita/issues/new/choose).
- **A security problem:** see [SECURITY.md](SECURITY.md); do not open a public issue.

Never paste a real CV, profile text or a job application into an issue.
