# Customers

One file per employer, customer or broker you apply to more than once: `local/customers/<name>.md`,
copied from `_template.md`. What is useful across applications goes here, so the next one to the
same place does not start from zero. Files here are gitignored and stay on your machine; only this
README and the template are shared.

Facts about you never go here; they belong in your profile. Confidential tender documents do not
belong here either; link to where they are stored instead.
